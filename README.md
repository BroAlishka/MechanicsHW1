# Домашнее задание 1

Добавлены спринт и взаимодействие. При нажатии E вызывается делегат и появляется сообщение `Interaction triggered!`. В Animation Blueprint добавлено состояние Sprint.

Во время спринта выносливость уменьшается. На нуле персонаж перестаёт бежать. Без спринта выносливость восстанавливается по 5 единиц в секунду. Её значение видно на экране.

## Управление

- WASD — движение
- Мышь — камера
- Пробел — прыжок
- Left Shift — спринт (удерживать)
- E — взаимодействие

## Запуск

Открыть `MechanicsHW1.uproject` в Unreal Engine 5.8 и нажать Play.
